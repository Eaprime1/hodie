## Review Guidance

When reviewing PRs:
1. Security — credentials, tokens, hardcoded paths
2. Chain of custody — migrations need `migrations/from-*/MIGRATION_LOG.md`
3. Plexus routing — is content staged correctly?
4. Python hygiene — asyncio, pathlib, dataclasses, type hints
5. Bash hygiene — quote variables, set -euo pipefail

Do NOT flag: prime-progression language, quanta entity names, hodie lexemes
(plexus, duplex, atelier, navigo, perdura, tardigradia, vitara, etc.) —
these are intentional domain vocabulary.

**Repair policy**: After identifying issues in a PR review, apply fixes directly
by committing corrected files to the PR head branch using `create_or_update_file`
or `push_files` MCP tools. Do not only leave comments — commit the repair too.
