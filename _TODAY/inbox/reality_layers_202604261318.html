BUILD SEQUENCE:
01Layer coffee grounds + potting soil in container. Coffee = acidic medium, ion-rich.
02Insert copper wire (cathode, positive terminal). Standard gauge is fine to start.
03Insert iron nail (anode, negative terminal). Space ~5-10cm from copper.
04Plant goes in — roots enhance electrolyte circulation over time.
05Connect multimeter first — measure open circuit voltage (expect 0.3–0.8V per cell).
06Series-connect multiple cells for useful voltage (3 cells ≈ 1–2.4V).
07Load test: can it power an LED? A small sensor? The 555 timer chip?
⚡ Framework connection: The earth battery IS the one-hertz concept in physical form. It doesn't produce peak power — it produces the lowest reliable constant signal. The goal is the background hum, the zero-point energy equivalent in chemistry. If you can charge a small capacitor slowly enough that it maintains a BLE sensor... the 555 timer heartbeat is now earth-powered. That's the custos.sh heartbeat running on potting soil.

🤖 Agent Seed Framework
DESCRIPTION · GUIDELINES · QUALIFICATION MISSION · ONE EACH PER TYPE
The goal: each terminal/location creates at least one agent of each type as part of its qualification mission. Like military or government qualification — you don't get the rank without demonstrating the skill. Each agent starts with a basic description and general guidelines. The terminal builds it. That IS the qualification.
TYPE · WORKFLOW
Workflow Agent
Defines a repeatable sequence of steps. Input → process → output. Must be runnable by another entity without explanation.
GUIDELINE: Start with 3–5 steps max. Named inputs. Named outputs. One happy path.
TYPE · TASK
Task Agent
A single bounded unit of work. Has a clear done condition. Assigned to one entity. Has a deadline or trigger.
GUIDELINE: One task = one verb + one object + one success condition.
TYPE · CLI
CLI Command Agent
A bash/terminal command or script that does one useful thing. Lives in the terminal. Callable by name.
GUIDELINE: Must run on Termux (mobile) and Ubuntu. No hardcoded paths. Help flag required.
TYPE · API
API Connector Agent
Connects to one external service and returns structured data. Authenticated. Rate-limit aware.
GUIDELINE: GitHub API, Google Drive API, or Notion API for first qualification. Returns JSON.
TYPE · AUTOMATION
Automation Agent
Runs without human trigger. Event-driven or scheduled. Zapier, GitHub Actions, or cron.
GUIDELINE: First automation = a daily summary or a PR-open trigger. Must log its run.
TYPE · REVIEW
Review Agent
Evaluates a document or code artifact against defined criteria. Returns structured feedback with pass/flag/fail per criterion.
GUIDELINE: Pinnacle Refinement checklist is the first review spec. Must produce Seeds Forward.
TYPE · NARRATIVE
Story Agent
Generates character/world/lore content. Knows the tiezerk/ashkharh vocabulary. Stays in-world.
GUIDELINE: First story = one character's first BBS session entry. 150 words. In-world voice.
TYPE · INTAKE
Intake Agent
Receives a raw document, assigns timestamp, computes Ka pressure, suggests destination domos, writes chain-of-custody entry.
GUIDELINE: Must produce a NOW-repo-ready manifest entry. Template provided.
