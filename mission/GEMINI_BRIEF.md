Every concept has a plexus level based on how many streams it can handle simultaneously:

| Stage | Streams | Role | Key Property |
|-------|---------|------|-------------|
| simplex | 1 | Single lexeme, infinite depth | Is this copy current? yes/no/maybe |
| duplex | 2 | Carbon + Shadow | Polarity keeper; first duplicate holder |
| triplex | 3 | Transistor / Superposition gate | Signal routing; switches state based on input |
| quadroplex | 4 | Synergy | Fourth stream creates the fifth thing |
| quintoplex | 5 | Control pad (4 fingers + thumb) | Full instrument access |

**Triplex as Transistor**: Triplex is the gate — it opens superposition.
Three streams enter; the triadic relationship determines which path amplifies and which attenuates.
Like a transistor: small input signal controls large output flow.

**Plexus Law**: Running more streams than your plexus level creates antagonist pressure → structural error.
